Tested on BetaFPV 900TX + BetaFPV SuperD 900 RX, HAPPYMODEL ES900, BYKRC, EMAX, and many other modules including LR1121 based

General info
============

Custom firmware supports:
 - custom frequencies (who might have thought!)
 - switching video channels during flight easilly just with any switch on your handset (works with relay drone as well)
 - some non compatible changes to mitigate spoofing/hijack of the link

WiFi is not advertized, so you need to add it on your PC/phone first:
wifi: ELRS RX CUSTOM / ELRS TX CUSTOM
passwd: elrs_custom

ELRS Module Hostname/IP
hostname: elrs_rx_custom.local / elrs_tx_custom.local
ip: 10.0.0.13


Folder structure
================
3.5.3 - Custom Firmware based on original ELRS 3.5.3 version. Compatible with standard ELRS
3.5.3-nocompat - Custom Firmware based on original ELRS 3.5.3 version with additional modifications to resist spoofing/hijack. NOT compatible with standard ELRS. I personally do not think anyone is using spoofing.
RX,TX - earlier versions of Custom Firmware, well tested.
